# Luxury UI

Мінімалістичний преміум інтерфейс на Next.js з Tailwind CSS та Framer Motion. Інтерфейс українською.

## Стек

- **Next.js 14** — React-фреймворк
- **Tailwind CSS** — утилітарні стилі
- **Framer Motion** — анімації
- **TypeScript** — типізація

## Стиль

- Мінімалізм, преміум-відчуття як у люксових брендів
- Кольори: крем, charcoal, stone, золотистий акцент
- Шрифти: Playfair Display (заголовки), Cormorant Garamond (текст)
- Широкий letter-spacing, багато «повітря», плавні анімації

## Запуск

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000).

## Скрипти

- `npm run dev` — режим розробки
- `npm run build` — збірка
- `npm run start` — продакшн-сервер
- `npm run lint` — перевірка ESLint
